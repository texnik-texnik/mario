# Super Mario Web Edition 🍄🕹️

Полноценная игра **Super Mario** на чистом веб-стеке (HTML5 Canvas + ES6 JavaScript + Web Audio API).
Работает полностью автономно (offline-first), без внешних тяжелых библиотек и сторонних ассетов.

## 🌟 Особенности

- 🎮 **4 классических мира**:
  - **World 1-1**: Знаменитый зеленый наземный мир с трубами, гумбами, купами и замком на финише.
  - **World 1-2**: Подземный синий мир с кирпичным потолком, трубами и тайниками с монетами.
  - **World 1-3**: Высокогорный уровень с парящими платформами над пропастью и коварными прыжками.
  - **World 1-4**: Замок Боузера с лавой, огненными преградами и финальным боссом Боузером на мосту с топором!
- 🎨 **Процедурный Retro Pixel-Art**:
  - 100% Canvas-рендеринг спрайтов без размытия и битых ссылок на картинки.
  - Марио (Маленький, Супер Марио, Огненный Марио, Звездный неуязвимый Марио).
  - Враги (Гумба, Купа Трупа с механикой пинка панциря, Растение-пиранья, Боузер).
  - Блоки с вопросом `?`, разбиваемые кирпичи, трубы, замок, флагшток, облака и холмы.
- 🔊 **8-битный звук через Web Audio API**:
  - Полный синтез звуков: прыжки, монеты, топтание врагов, фаерболы, бонусы, смерть, фанфары победы и Game Over.
  - Фоновые чиптюн-мелодии для наземных уровней, подземелья, замка и режима Звезды!
  - Кнопка выключения/включения звука с сохранением состояния.
- 📱 **Полная поддержка мобильных устройств**:
  - Экранный геймпад (D-Pad и кнопки A / B) для комфортной игры на смартфоне или планшете в Termux.
  - Поддержка мультитача без залипания кнопок и масштабирование под экран.
- ⌨️ **Управление с клавиатуры**:
  - `←` `→` или `A` `D` — движение влево / вправо.
  - `↓` или `S` — присесть (для Супер/Огненного Марио).
  - `Пробел` или `W` / `Z` / `K` — прыжок (высота прыжка регулируется удержанием).
  - `Shift` или `X` / `J` — бег с ускорением / стрельба фаерболами.
  - `P` или `Esc` — пауза.
  - `M` — вкл/выкл звук.
  - `R` — перезапуск уровня.

## 🚀 Запуск игры

Вы можете открыть `index.html` в любом современном браузере или запустить локальный HTTP-сервер в Termux:

```bash
python -m http.server 8080
```
Затем откройте в браузере: `http://localhost:8080`
